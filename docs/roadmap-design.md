# Deliberate practice and the roadmap studio

## Decision before implementation

A learner should be able to set a capability, inspect the evidence for a prerequisite, choose a demanding next question, and later correct the evidence on which the choice depended. A prompt assembled in the browser is editable and runs only when the learner takes it to a tutor. The study goal starts blank.

Use a static, loopback-served application, a versioned exchange with the existing session format, and a short skill route with a separately loaded reference. A hosted tutor and database would add identity, cost and deletion obligations. A standalone tree of checked boxes would lose the distinction between exposure and demonstrated ability. Begin with six skills in signals and sampling. The existing analytic certificate supplies a reference result and a measurement counterexample. Render unfamiliar valid graphs from their prerequisites.

The publication checkout matched remote main at `1bc3ccf735c440116bb97cc875940630f61828da`. It was clean on `revision7-evidence-led-tutoring`. The separate local main was two commits behind. Preserve both branches. The baseline has 225 tracked files totaling 2,712,053 Git-blob bytes. The runtime contains 41 files totaling 231,674 bytes. The entry is 5,079 bytes and 744 whitespace-delimited words. Entry plus the practice reference totals 2,938 words. These are possible route costs. Actual model input also depends on host instructions, history and tools.

Revision 7 already has source validation, an explicit runtime allowlist, v1 private records, a question bank, Markdown milestones, assistance and attribution guards, and analytical and browser checks for sampling. The workspace's earlier roadmap preview simulated evidence states with a selector. The release lacks a persistent interactive study workflow. Its recorded primary candidate fell from 47 full passes to 44 across 48 judgments. In a subsequent narrow fresh comparison the repaired version earned 16 full passes to the baseline's 13. Revision 6's transfer result depended on the interpretation of a grading criterion. These are judgments of simulated tutor output. No retained learner performance follows from them.

Read the full Jane Street tutor and MIT license at `7c6715c29548a3b39d4a9545c698ee4fd17a7213`. Adopt a question that discriminates between explanations, checks of actual outputs, and changes of difficulty. Preserve immediate solutions, a learner's right to stop, and scoped record access. A fixed placement interview and a universal level scale conflict with those choices. Preserve the existing notice. The public getcracked canvas showed named topic cards, descriptions, activity counts, a recenter control and some locked entries. Its public view guided organization only. Gated workflows were outside the observation.

## Work and ownership

1. Freeze a separate synthetic evaluation outside implementers' context. Archive packet hashes, model conditions, replies, masked judgments, discrepancies and exceptions.
2. Instruction owner updates the tutoring routes and runtime manifest. Graph owner implements the pure model, v1 bridge, format guide and deterministic tests. Integration owner builds the site and browser checks. Cross-check the mode names, date policy and assistance fields at their interfaces.
3. Inspect the working site with synthetic evidence, exercise failure paths, refine and rerun. Review the combined diff independently and check the generated keys.
4. Commit the reviewed files locally. Compare both package sizes, repeat the clean install and browser verification, and publish a local-run guide with screenshots and remaining evidence gaps.

Personal records stay in the learner-selected workspace or in this browser profile after explicit local saving. The site has no remote requests, model client, telemetry or scheduler. The browser cache holds only the static application. Imported data and learner-supplied source text remain data when composing a prompt.
